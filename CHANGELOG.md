# Changelog

## [1.0.0] - 2026-09-30

### Added
- PowerPoint native Custom Task Pane.
- Font family fuzzy search and dropdown.
- Live font and weight synchronization from the current selection.
- Custom weight slider with click, drag and mouse-wheel interaction.
- Font-size spinner with typing, buttons, wheel and vertical scrubbing.
- Character-spacing and line-spacing controls.
- Italic, case cycling, subscript and superscript controls.
- Current-slide text-box fitting tool.
- PowerPoint-red UI and DESIGN BY SUKIN signature.

### Notes
- Windows x64 only for this release.
- Variable-font support depends on what PowerPoint COM exposes reliably.
